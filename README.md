# OzFish paper — LaTeX project for *Engineering Applications of Artificial Intelligence*

This repository contains the LaTeX-formatted version of the OzFish fine-grained fish-classification paper, prepared for the Elsevier journal *Engineering Applications of Artificial Intelligence* (EAAI).

**Important author instruction:** preserve the wording of the paper. Do not rewrite, paraphrase, proofread, correct, add, or remove manuscript text as part of formatting work unless the authors explicitly approve a text change. Use this README to track unresolved submission items; do not silently fill in missing author details, declarations, keywords, model names, or other information.

**Guideline status:** reviewed on 13 October 2026. The live ScienceDirect author-guide page was not fully accessible during the check. Some supplemental/archived EAAI guidance and recent third-party guides conflict on whether highlights and a graphical abstract are mandatory. Items whose current status could not be confirmed are marked for verification below. The live EAAI Guide for Authors and submission portal take precedence.

### File types that are not currently needed

- **`.sty`:** there is no custom project style file. `main.tex` loads standard LaTeX packages.
- **`.bib`:** the current source uses a `thebibliography` environment with 66 `\bibitem` entries in `main.tex`; there is no separate BibTeX database in this project.
- **`.aux`:** generated by LaTeX for citation and cross-reference bookkeeping. Do not edit.
- **`.log`:** generated compilation log. Read it when troubleshooting; do not edit.
- **`.toc`:** generated table-of-contents data if a contents list is enabled. It is not manuscript source.
- **Other build files** such as `.out`, `.fls`, `.fdb_latexmk`, and `.synctex.gz` may be generated by the chosen editor/compiler; they are not source files.

## Compile the paper

### Overleaf or another online LaTeX editor

1. Import the repository files (or upload the project ZIP).
2. Set `main.tex` as the main document.
3. Use the XeLaTeX compiler if available, since the current source was compiled with XeLaTeX and contains Unicode support.
4. Recompile and inspect both the PDF and the compilation log.

### Local build

With a TeX distribution and `latexmk` installed, a typical command is:

```bash
latexmk -xelatex -interaction=nonstopmode main.tex
```

Build output such as `.aux` and `.log` is generated automatically. The committed `main.pdf` is a preview, not the source of truth; `main.tex` and the image files are the editable project.

### Front matter and abstract

- [ ] **Keywords — missing.** Add a `keyword` block immediately after the abstract using EAAI's supported `elsarticle` structure. The EAAI author information pack located during review says **a maximum of 6 keywords**, not a minimum of 6. Prefer specific indexing terms; avoid overly broad or plural terms, combined concepts, and abbreviations that are not firmly established in the field. Confirm the maximum and exact instructions against the live guide.
- [ ] **Author affiliations — missing/incomplete.** The source currently puts all ten names in a single `\author{Contributors: ...}` command. Associate each author with the correct department/institution and full institutional address. Add affiliation markers as appropriate. This requires author-supplied facts.
- [ ] **Corresponding author — missing.** Identify the corresponding author and supply the contact details requested by the journal, including email and postal address if required. Do not guess these details.
- [ ] **Abstract length — verify against current guide.** The current abstract is about 234 words and has no citations. A 250-word maximum is reported in the guidance located during review, but confirm the applicable limit for this article type in the current EAAI guide.
- [ ] **Acronyms/model names in the abstract — review.** The abstract contains `DINOv3` and `MATANet` without expansion. Check EAAI's rule about undefined acronyms in the title and abstract and determine how these proper model names should be treated. Do not silently expand or change them; get author approval for any text change.
- [ ] **First-page abbreviation footnote — verify.** Older EAAI author information says non-standard abbreviations should be defined in a first-page footnote and unavoidable abstract abbreviations defined at first mention in the abstract. Confirm whether this instruction remains in the current guide.
- [ ] **INSPEC classification codes — verify.** Older EAAI guidance asks for up to six standard INSPEC codes. No codes are included in this source. Confirm whether they are still requested and, if so, obtain appropriate codes.

- [ ] **Declaration of competing interests.** Supply the appropriate declaration based on the authors' actual circumstances and any journal-provided form or wording.

### LaTeX structure, tables, equations, and references

- [x] **Single-column layout.** The current PDF is single-column, using the `elsarticle` preprint layout.
- [ ] **Section-numbering structure.** Many headings use starred commands such as `\section*{1. Introduction}` and include the number as literal heading text. For cleaner LaTeX structure and cross-referencing, consider switching to automatic section numbering while preserving the exact visible heading wording and numbering. This is a formatting change; do not rename headings.
- [ ] **Figures and tables.** The current project has six figures and nine `longtable` environments. Review float/longtable placement, text readability, captions, labels, references in the manuscript, and page breaks. Final placement is still subject to author review.
- [ ] **Equation verification.** Fourteen numbered equation environments are present. Check every symbol, subscript, superscript, summation, and coefficient against the original Word paper; the rendered equation must match the authors' intended formula. Do not infer or invent missing mathematical content.
- [ ] **Bibliography completeness and style.** The source contains 66 numbered `\bibitem` entries, and citation keys resolve in the current compiled PDF. Check each entry's metadata (authors, title, venue, year, volume/pages, DOI or URL where appropriate) against the original records and make sure it follows the current EAAI reference instructions. Missing metadata must be verified, not invented.
- [ ] **Page length — verify.** The compiled PDF currently has 47 pages. A third-party guide reported a 50-page limit, but that limit was not verified from the accessible live EAAI guide. Check any applicable word/page limits for the selected article type.
- [ ] **Compilation check.** After any change, recompile and check `main.pdf` and the `.log` for errors, unresolved references, missing images, overfull boxes, and layout problems. A successful PDF compilation alone does not confirm journal compliance.
