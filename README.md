# OzFish paper — LaTeX source for Engineering Applications of Artificial Intelligence

## Main source
- `main.tex`: the paper text, title/contributor line, equations, tables, figures, and numbered references. This is the only LaTeX source file that needs direct editing for the current version.
- `figure1.png` … `figure6.png`: figure artwork extracted from the uploaded Word document and referenced by `main.tex`.
- `main.pdf`: a compiled preview (provided separately; it can be regenerated by recompiling `main.tex`).

## Elsevier-specific files
- `elsarticle.cls`: the Elsevier article class is included in this project archive so the project can compile in editors that do not already provide it. Do not edit this class file.
- `.sty`: no custom style file is needed; `main.tex` loads standard LaTeX packages from the editor's TeX distribution.
- `.bib`: not required in this version. The 66 existing references are formatted as `thebibliography` entries inside `main.tex` to preserve their source text. If you later choose BibTeX, these can be moved to a `references.bib` file without changing the paper wording.

## Generated files (do not edit manually)
- `.aux`: LaTeX cross-reference/citation bookkeeping.
- `.log`: compilation log.
- `.toc`: table-of-contents data, generated if the document requests/displays a contents list.
- `.pdf`: compiled output. It is not the editable source.

## Compile
In Overleaf, upload this folder's contents (or import the ZIP) and set `main.tex` as the main document. Locally, a common build command is `latexmk -xelatex -interaction=nonstopmode main.tex`.

## Text-preservation note
The wording was not deliberately rewritten, proofread, or corrected. The fourteen numbered formulas are displayed as equation environments; this changes only their LaTeX presentation. The original figure/table positions may need author review. No keywords or affiliations were invented, and existing `(model name)` placeholders and the note about deciding figure/table placement remain as in the source.
